V74 is a public Partner-site design and visual-content refinement release. Partner authentication, portal data, incentives and Admin chat continue to use Apps Script V63.

- frontend 74.0.0;
- backend contract 63.0.0;
- partner.inrishi.in custom domain;
- GitHub Actions live-backend gate before build/deploy;
- no local-development step in production workflow.
